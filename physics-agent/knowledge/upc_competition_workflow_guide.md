# UPC 国际大学生物理竞赛全流程辅导与人机协作工作流规范 (48h Full-Cycle Protocol)

> **文档属性**：专为 UPC 竞赛打造的“解题—建模—仿真—优化—论文”全流程 AI 辅导与协同工作流标准  
> **归档位置**：`physics-agent/knowledge/upc_competition_workflow_guide.md`  
> **指导基线**：综合《UPC-ai指导.md》（解题与科研思维）、《论文说明.docx》（论文六大固定环节与八章模板）、以及 MATLAB R2023b 战备模版库  
> **执行定位**：AI 智能体担任“第一性计算副驾、数值仿真引擎与同行评审员”，人类选手掌舵“物理把控、假设裁定与 Word 终稿撰写”。

---

## 一、 核心指导哲学：从“做题”转向“限时微型科研”

1. **不可替代的人机分工边界（Division of Responsibility）**
   - **人类选手主导主权（The Commander）**：
     - 审定现实物理假设的合理性与取舍；
     - 在 Microsoft Word (`.docx`) 中组织和撰写英文论文正文；
     - 在 MATLAB 交互界面中旋转、审视 3D 轨迹/曲面，确定最优出版视角。
   - **AI 智能体计算副驾（The Co-pilot & Reviewer）**：
     - **第一性原理拆解**：提取核心作用力、无量纲特征数（$Re, Ma$ 等）与特征尺度；
     - **状态空间方程推导**：将二阶动力学/非线性 PDE 转化为标准一阶状态空间形式 $\dot{\vec{Y}} = \vec{F}(t, \vec{Y})$；
     - **MATLAB 仿真与打靶求根**：调用预置战备模板，执行无头静默仿真、参数扫描与 300 DPI 出图；
     - **严格同行审阅（Peer Review）**：对照论文六大环节与五大防线，审阅选手的论文草稿，指出物理漏洞与量纲矛盾。

2. **坚决杜绝的四大竞赛典型错误**
   - **盲目复杂化**：一开始就上重型 CFD 或复杂数值，耗费大量时间却未增加物理洞察。**铁律：必须先建立 Version 0.1 最简基线模型，证明基线能够解释什么、缺失什么，再逐步引入现实因素**。
   - **文献检索过载**：收集几十篇文献却无法说清解决了什么问题。**铁律：文献必须服务于当前模型的具体参数、公式或验证基准，够用即停**。
   - **过度追求无关精度**：若某个参数不确定性远小于模型系统误差，无需花数小时精雕细琢。
   - **无限探索不收口**：进入比赛后半程（36h 后）必须建立收口意识，禁止随意推倒重构，全力转向验证、图表与论文论证。

## 二、 48 小时极速科研五阶段实战流水线

```
[Phase 1: 0~3h 破题与机制解构] ──> [Phase 2: 3~12h 最简基线V0.1与初算] ──> [Phase 3: 12~28h MATLAB高保真仿真与全域优化]
                                                                                        │
[Phase 5: 44~48h 极限自洽检验与终稿交付] <── [Phase 4: 28~44h Word学术论文写作与AI同行评审] <┘
```

### Phase 1：破题、问题拆解与数量级估算 (T+00h ~ T+03h)
1. **题目一句话概括**：用一句话提炼核心课题（例如：“研究在变密度跨音速大气下，阻力危机与阵风如何影响火炮弹道的有效击中窗口”）。
2. **多小问逻辑链解构**：
   - 区分哪些是题目直接给定的参数，哪些是隐含给定的物理机制，哪些必须自行估算；
   - 区分“决定系统基本行为的主导因素”（如重力、动压阻力）与“仅微调精度的次要因素”（如科里奥利力、湿度微扰）。
3. **前置费米数量级估算**：
   - 估算特征时间尺度 $\tau$、特征速度 $v$、特征无量纲数（马赫数 $Ma = v/c_s$、雷诺数 $Re = \rho v d / \mu$）；
   - 判定流动区态（斯托克斯区 $F \propto v$、牛顿阻力区 $F \propto v^2$、还是跨音速激波剧增区）。

### Phase 2：建立 Version 0.1 最简基线模型 (T+03h ~ T+12h)
1. **基线先行原则**：构建最简解析或简易数值模型（如理想真空抛物线、常物性导热、单自由度线性振动）。
2. **让系统第一时间跑起来**：
   - 获得第一批定量结果与时序曲线；
   - 暴露系统核心矛盾，为后续高保真模型确立对比参考基准（Benchmark）。

### Phase 3：MATLAB R2023b 高保真建模、数值仿真与逆向优化 (T+12h ~ T+28h)
1. **算法与模板匹配**：对照 `physics-agent/knowledge/matlab_upc_guide/README.md` 选取金牌模板：
   - 大气弹道/逆向击中：`template_ballistics_shooting.m` (`ode113` + `fzero`)；
   - 多级事件/阶跃动力学：`template_multistage_events.m` (`ode45` + `odeset('Events')`)；
   - 连续推力轨道：`template_orbital_continuous.m` (`ode113` + 守恒量检验)；
   - 参数敏感性云图：`template_param_sweep_heatmap.m` (`meshgrid` + `contourf`)；
   - 阵风扰动/蒙特卡洛：`template_monte_carlo.m` (2000点抽样 + 95% 置信椭圆)；
   - 瞬态导热/气体扩散：`template_pde_heat_diffusion.m` (`pdepe`)；
   - 耦合振动/声学共振：`template_vibration_acoustics.m` (`eig` + `ode45` + `fft`)。
2. **仿真五大防线注入**：
   - 环境分层机理（ISA 大气 + 萨瑟兰公式）；
   - 终止边界严格事件截断（`odeset('Events')`，杜绝固定 $t_{end}$ 瞎猜）；
   - 逆向求解打靶化（`fzero` / `fminbnd` 求根）；
   - 现代 MATLAB 向量化与点乘保护（杜绝隐式维度错误）。
3. **发掘超越单一数字的科研深度**：
   - 运行双参数全域敏感性扫描（`meshgrid` 30x30 以上网格）；
   - 提取最大值脊线、最优操作区间或稳定性相图；
   - 导出符合出版级规范的 300 DPI 矢量质感图表（纯英文 LaTeX 标注）。

### Phase 4：Word 论文组织与 AI 过程同行评审 (T+28h ~ T+44h)
1. **基于标准 Word 模板写作**：
   - 使用知识库预置模板：`physics-agent/knowledge/paper_templates/UPC_Paper_Standard_Template.docx`；
   - 严格按照八章学术结构组织内容。
2. **AI 同行评审员介入**：
   - 人类将草稿内容或各章节要点发给 AI；
   - AI 对照“论文六大固定逻辑环节”进行穿透审阅，挑出量纲不平衡、假设矛盾或结论证据链不足的问题。

### Phase 5：极限自洽检验、细节冻结与封包 (T+44h ~ T+48h)
1. **极端退化极限自洽检验（Asymptotic Consistency）**：
   - 当阻力系数 $C_D \to 0$ 时，模型是否能无缝退化为经典解析解；
   - 当扰动趋于 0 时，守恒量（能量、动量）是否在数值容差内严格守恒。
2. **论文格式与数据自洽性审查**：
   - 检查摘要四要素配比（目标15-20%、方法25-30%、定量结果30-40%、结论与价值15-25%）；
   - 核验图表编号、物理单位、有效数字与正文数字完全一致；
   - 确认无中文字符混入 LaTeX 图例，生成最终 PDF。

## 三、 论文六大固定逻辑环节与八章架构对照

| 逻辑环节 (思维链) | 核心回答的科学问题 | 对应论文标准章节 | AI 辅导与评审核心抓手 |
| :--- | :--- | :--- | :--- |
| **01 明确问题** | 我要解决什么？ | 1. Introduction (1.1~1.4) | 确保引言指出真实物理困难，任务拆解清晰，拒绝套话 |
| **02 定义边界** | 我研究什么、不研究什么？ | 2. Assumptions, Parameters & Notations | 检查假设是否有物理依据，符号与单位表是否完备 |
| **03 建立模型** | 用什么物理规律解决问题？ | 3. Baseline Model & 4. Core Numerical Model | 方程一阶状态空间化，子模型机理明确，求解算法有据 |
| **04 求解与分析** | 模型算出了什么？ | 5. Simulation Results and Discussion | 拒绝单一数字，必须呈现全域参数热力图、极值脊线与置信椭圆 |
| **05 检验模型** | 凭什么相信结果？ | 6. Model Validation & Verification | 极端退化检验、守恒量校验、步长/容差敏感性测试 |
| **06 交付答案** | 最终结论与工程价值是什么？ | 7. Regimes of Validity & 8. Conclusion | 逐一回答赛题各问，明确给出适用边界与失效范围 |

## 四、 人机协作标准 Prompt 交互集（供参赛选手即取即用）

### 交互 1：输入模拟题/赛题，请求第一性解构与破题路线
```text
【输入题目】: [粘贴赛题全文]
【请求任务】: 请作为 UPC 物理竞赛专家，按照《UPC全流程辅导规范》为我们进行 Phase 1 破题指导：
1. 用一句话凝练本题的核心物理课题与攻坚目标；
2. 拆解题目的多小问递进逻辑链，区分题目已知量、隐含物理机制与需自主估计的参数；
3. 进行特征时间/速度/尺度的费米数量级估算，并计算特征无量纲数 (如 Re, Ma)，判定主导物理区态；
4. 推荐 Version 0.1 最简基线模型路线，以及后续高保真 MATLAB 求解器与模版匹配。
```

### 交互 2：请求 MATLAB 高保真建模脚本与 300 DPI 出图
```text
【当前模型】: 我们已确立了控制方程 [简述或粘贴方程]，考虑了 [变密度ISA大气/阻力危机/风场/热传导...]。
【请求任务】: 
1. 给出标准一阶状态空间形式 dY/dt = F(t, Y)；
2. 编写符合 MATLAB R2023b 规范的完整独立脚本（包含事件函数截断、点乘保护与 300 DPI exportgraphics 导出）；
3. 如果涉及目标反求，请编写外层 fzero / fminbnd 打靶求解模块；
4. 运行双参数二维扫描，导出符合出版级规范的双联/三维全英文科研图表。
```

### 交互 3：请求论文草稿的学术同行评审（Peer Review）
```text
【论文草稿片段】: [粘贴撰写的摘要、假设、模型或结果章节]
【请求任务】: 请严格对照《论文说明.docx》六大固定逻辑环节与五大防线对本段进行同行学术评审：
1. 物理机理是否严密？是否存在隐式未声明假设或量纲不一致？
2. 结果论证是否充分？是否只罗列了孤立数字而缺乏物理规律解释？
3. 英文表达与学术结构是否符合 UPC 特等奖论文标准？请指出具体修改建议。
```
