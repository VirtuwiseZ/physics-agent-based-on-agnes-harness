## 一、 战略共识与核心定位转型

经过与人类开发者的深入沟通，对原项目路线进行了关键纠偏，确立了以**“人类主导成果产出，DSH 充当深度计算副驾与学术顾问（Co-pilot & Scientific Consultant）”**的核心定位：

### 1. 任务阶段优先级定调
- **第一优先级（3 周内）**：全力集中攻坚大学生物理竞赛（UPC 等，48 小时实战）；
- **第二优先级（赛后长远）**：大学非物理专业的平时课内作业与课程指导，推迟至 UPC 竞赛完赛后开启。

### 2. 成果交付边界界定（人机明确分工）
- **坚决不做的功能（杜绝越俎代庖）**：
  - **不自动生成端到端的完整 LaTeX 论文**：参赛论文由人类团队在 Microsoft Word (`.docx`) 中主导撰写、排版与推敲，确保团队对物理实质 100% 掌控，规避 AI 论文套话与学术诚信隐患；
  - **不自动强行生成最终展示图**：最终图表由人类在专业科学计算软件（MATLAB 等）中交互调整视角、样式与尺寸后贴入论文。
- **DSH 的核心使命与主战场**：
  - **破题与物理架构咨询**：接收赛题后，提供第一性问题解构、主导效应筛选、控制方程推导、无量纲群提炼、合理数量级预估与总体分析步骤建议；
  - **深度对接 MATLAB R2023b 计算与过程性文档**：不仅仅是“复制代码”，而是实现 DSH 与本地 MATLAB 的输入输出连通、过程数据读取、图表视觉审阅、算法报错自动排查与中间草稿同行评审。

## 二、 本地 MATLAB R2023b 深度对接可行性实测结论

已在宿主机完成全套实测，证实 DSH 与本地 MATLAB 具备原生、深度协同的完美基础：

1. **宿主环境验证**：
   - 本地已安装：`D:\matlab\Matlab 2023b 64bit\bin\matlab.exe`（版本 23.2.0.2365128 R2023b）；
2. **突破 Windows Sandbox 权限限制**：
   - **痛点**：DSH 沙盒环境默认隔离用户 `AppData\Roaming`，导致 MATLAB 原生启动报错 `无法访问预设项文件夹`；
   - **解决方案**：在工作区重定向预设目录：`$env:MATLAB_PREFDIR = "E:\agnes-harness\.matlab_prefs"`；
   - **实测结果**：在 DSH 的 `pwsh` 工具下，通过 `matlab -batch "..."` 可以免提权原生秒级启动 MATLAB 批处理，并已成功实测运行 `ode45` 解微分方程输出！
3. **协同数据链路规划**：
   - **执行链路**：DSH 编写/调试 `.m` 脚本 $\to$ 通过 `pwsh` 静默运行或提示人类在 MATLAB GUI 中调试；
   - **数据链路**：MATLAB 输出 `.mat` 矩阵 $\to$ DSH 通过 Python `scipy.io.loadmat` 直接提取并分析矩阵数值；
   - **视觉闭环**：MATLAB `exportgraphics` / `saveas` 导出 `.png` $\to$ DSH 调用 `read_image` 工具直接“肉眼”检阅图表，判断曲线是否发散、有无奇点、趋势是否符合物理；
   - **文档审阅**：人类在任务目录下编写的阶段性思考笔记（Markdown / 文本草稿），DSH 随时读取并给出严谨性批判与补充建议。

## 三、 实战协同工作流设计（UPC 48 小时实操模式）

```text
[阶段 1: 赛题输入与破题]
  人类在聊天窗粘贴 UPC 赛题
    ⬇
  DSH 提取核心物理对象、场与目标，给出：
  • 一句话研究课题
  • 主导机理 vs 次要微扰
  • 推荐建立的微分方程组与首选 MATLAB 求解器
  • 推荐参数取值与渐近退化边界
  • 分步研究规划路线图

[阶段 2: 深入推导与代码协同]
  人类按规划展开分析，DSH 提供：
  • 符号方程展开与矩阵推导
  • 专为 MATLAB R2023b 优化的仿真脚本（参数化、ODE 事件检测、向量化）
  • 自动执行/排查 MATLAB 报错

[阶段 3: 中间过程数据与图表审阅 (Vision Loop)]
  MATLAB 计算并导出 .mat 数据与 .png 图像
    ⬇
  DSH 调用 read_image / Python 读入分析：
  • 检查是否出现非物理发散、虚假伪收敛
  • 评估曲线趋势与物理极限定量符合度
  • 给出进一步敏感性扫描区间建议

[阶段 4: 过程文档评审与论文支撑]
  人类撰写阶段性草稿 / Word 提纲
    ⬇
  DSH 进行“同行评审（Peer Review）”：
  • 挑出物理假设漏洞与表述不严谨之处
  • 润色核心结论摘要与物理讨论深度段落
  • 人类在 Word 中整合完成最终论文
```

## 四、 核心武器库升级清单（面向 MATLAB R2023b）

1. **MATLAB R2023b 物理仿真算法知识体系**：
   - 刚性与非刚性微分方程解法选型（`ode45` vs `ode15s` vs `ode23t`）；
   - 微分方程事件停止函数（`odeset('Events', @event_func)`，如弹道着地、逃逸速度达到时即刻截断）；
   - 偏微分方程（`pdepe` 一维抛物/双曲型、二维网格差分）；
   - 参数拟合与多目标寻优（`lsqcurvefit`, `fmincon`）；
   - 现代化绘图与导出规范（`tiledlayout`, `yyaxis`, `exportgraphics` 高 DPI 无损图）；
2. **轻量自动化辅助工具**：
   - 封装 MATLAB 执行与数据交互辅助函数，彻底免去手动来回复制小数值的繁琐摩擦。
