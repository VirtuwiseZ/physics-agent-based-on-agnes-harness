## 一、 当前系统的客观自省与问题诊断

在前期工作中，系统已跑通了基础的工程链路（如本地 MATLAB 批处理调用、Windows 沙盒日志写隔离、学术图表无头导出、以及 Word 论文模板骨架生成）。但站在物理教学与竞赛指导的实际标准来审视，当前系统仍存在较为明显的结构性缺陷与思维惯性：

### 1. 物理学科覆盖的单一性与局限性
- **现状**：现有的 7 套 MATLAB 模板中，有 4 套（外弹道、跳伞多阶段、参数扫描、蒙特卡洛）其物理内核均聚焦于“质点牛顿第二定律 + 气动阻力”，本质上是近几年特定力学赛题的就题论题。
- **缺失**：
  - **刚体姿态动力学**：缺乏欧拉角、角速度矢量微分方程与转动惯量张量计算范式，难以处理非球对称物体的翻滚、进动及落地碰撞反弹；
  - **空间矢量场与电磁相互作用**：缺乏空间三维电势/磁场分布（`quiver3`/`streamline`）及带电粒子在复合场中洛伦兹回旋与漂移的标准数值实现；
  - **波动与物理光学**：缺乏波前干涉叠加、双缝/多缝衍射与基于贝塞尔函数的艾里斑孔径光强积分；
  - **非线性动力学与热力学状态演化**：缺乏相空间相图（Phase Portrait）、分岔行为分析，以及辐射换热（$\sigma T^4$）与相变潜热平衡的通用范式。

### 2. 交互风格的“浮夸化”与形式主义黑话
- **现状**：提示词与系统说明中频繁出现“三道确定性物理工程防线”、“全生命周期闭环”、“毫秒级时序可穿透审计”等工程化和互联网化词汇。
- **问题**：在学术论文审阅与严谨科研推导中，此类词汇不仅无助于物理问题的解决，反而稀释了核心物理讨论的浓度。审稿人只关注物理机理是否自洽、控制方程推导是否正确、关键假设是否合理、数值结果是否有据可查。

### 3. 破题阶段的“重求解、轻物理”倾向
- **现状**：收到题目后容易快速滑动到“调哪个求解器、写哪段代码”的技术实现层面。
- **问题**：真实竞赛与微型科研的难点在于“从一段模糊的现实描述中提炼物理图像”。缺乏前置的受力/能量平衡草图、无量纲特征数判定（如 $Re, Ma, Kn, Pr$）以及数量级极限估算，容易导致后续在错误或不适用的物理模型上空转。

### 4. 验证环节的内卷自证（缺乏外部横向锚定）
- **现状**：目前的模型验证主要依赖“退化极限检验”（如令阻力系数趋近于零时退化为初等抛物线）。
- **问题**：退化检验仅能验证数学推导与数值积分的一致性，无法证明模型对真实物理世界的逼近程度。缺乏与公认物理常数、经典文献实验曲线、或者半经验理论公式的横向对比与误差量化。

## 二、 改进思路与指导原则

针对上述自省发现的问题，后续的改进工作遵循以下四项原则：

1. **去黑话化，回归学术语言**：
   - 全面梳理并清理提示词、内部说明及报告中的包装性词汇，用质朴、精确的物理学术术语（如“量纲齐次性检验”、“渐近行为分析”、“边界条件截断”）替代宣传性用语。
2. **物理机制先于数值计算**：
   - 确立“破题三部曲”：一句话核心课题 $\to$ 受力与能量机制解构 $\to$ 关键无量纲数与数量级估算。在人类选手未确认物理主导效应与最简基线模型前，不急于编写复杂数值代码。
3. **补充核心物理范式，不盲目引入重型第三方库**：
   - 针对刚体转动、空间电磁场、波动光学等空白板块，在 MATLAB 知识库中就地补充轻量、自包含的通用范式脚本，保持“无外部黑盒依赖、无头批处理稳定、300 DPI 英文 LaTeX 导出”的工程基线。
4. **验证手段立体化**：
   - 建立“数学自洽（退化极限）+ 物理合理（守恒量与敏感性）+ 外部锚定（文献或经验公式对比）”的三重验证意识。

## 三、 执行规划与分步实施清单

改进工作分为三个具体阶段推进：

### 阶段一：梳理规范与去黑话化（立即执行）
- [ ] **任务 1.1**：清理 `physics-agent/knowledge/upc_competition_workflow_guide.md` 和各 Skill 说明中的浮夸用语，统一为稳重严谨的物理学术表述。
- [ ] **任务 1.2**：在破题流程中明确强化“无量纲数与流动/动力学区态判定”的强制输出要求，确保大模型在提出模型前先交代适用机制。

### 阶段二：补全核心通用物理范式（逐步实施）
- [ ] **任务 2.1：刚体姿态动力学与定点转动范式**
  - 新建 `template_rigid_body_attitude.m`：包含转动惯量张量、欧拉角与角速度动力学方程（Euler's equations of motion），适用于自旋稳定、翻滚及进动分析。
- [ ] **任务 2.2：空间电磁场与带电粒子洛伦兹偏转范式**
  - 新建 `template_lorentz_particle_drift.m`：包含空间非均匀磁场/电场网格插值、三维场线绘制（`streamline` / `quiver3`）及带电粒子漂移轨迹高精度积分。
- [ ] **任务 2.3：波动光学干涉与衍射强度积分范式**
  - 新建 `template_wave_optics_diffraction.m`：包含多缝干涉、圆孔艾里斑衍射的光强分布积分（基于 `besselj`）与 2D/3D 光强分布云图导出。

### 阶段三：全流程实战检验（通过模拟题演练）
- [ ] **任务 3.1**：使用一道代表性模拟题（如包含非质点特性或复合机制的物理问题）进行全流程推演：
  1. 破题与机制解构（物理图像、无量纲数、数量级估算）；
  2. 建立 Version 0.1 最简基线模型并获得初算结果；
  3. 编写 MATLAB 高保真数值仿真脚本并生成 300 DPI 科研图表；
  4. 实施立体化验证（极限退化、守恒量校验、参数敏感性）；
  5. 产出符合八章规范的 Word 论文初稿。
- [ ] **任务 3.2**：根据推演中暴露的实际问题，进一步校准人机协同边界与脚本鲁棒性。
