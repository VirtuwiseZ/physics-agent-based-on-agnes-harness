## 核心维护规范
1. **重点聚焦 `notes-for-ai/`**：后续参与开发与维护的 AI 智能体，必须优先查阅 `notes-for-ai/`（特别是 `UPC竞赛协同与MATLAB对接战略规划.md`）；
2. **严守当前工作分支**：所有针对 UPC 竞赛、MATLAB 本地对接与大物硬实力提升的开发必须严格在 **`UPC`** 分支进行，严禁向 `main`、`physics-agent` 提交代码或推送；
3. **遵守通用语言风格**：任何新增或修改的内部技术备忘，均须遵循平实务实、简明扼要、不讲黑话、杜绝自吹自擂的标准语言风格。
